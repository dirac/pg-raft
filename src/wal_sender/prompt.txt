
The current implementation is blocking. Implement a wal sender using asio. The wal sender takes among other things the wal directory. It
will have a function that will be invoked periodically telling it it what extend the wal has
progressed (we will use the PgClient from status to query the postgresql primary server for the
testcase).

For test case, we have a primary postgresql (pgbench doing transactions). Using PgClint we will
query the primary for the wal lsn using
  "SELECT * FROM pg_walfile_name_offset(pg_current_wal_flush_lsn())" or something similar.
And send it to the standby.
