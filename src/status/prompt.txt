

Implement the postgresql client protocol using asio. The client should be able to execute simple
statement. The execution should be implemented using extended protocol. The sql statements don't
have any bind parameters. It always connects to postgresql server on localhost. The client API has
four functions (a) connect (b) prepare and (c) execute (d) close.

Assume the client doesn't need a database name and password. The connection will be non-ssl.

The usage will be like.
     conn = connect(port);
     sql_1 = conn.prepare("SELECT * FROM pg_walfile_name_offset(pg_current_wal_flush_lsn())");
     sql_2 = conn.prepare("SELECT pg_control_recovery().timeline_id;");

     conn.async_exec(sql_1, [] (....) { .. });
     conn.async_exec(sql_1, [] (....) { .. });
     conn.async_exec(sql_1, [] (....) { .. });
     conn.async_exec(sql_2, [] (....) { .. });

     conn.close()
